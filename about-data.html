数据与方法

贰处理方法

高程场　把 2048² 的 PNG 按蓝通道解码为米制高程（terrarium 编码：h = (R×256 + G + B/256) − 32768），再按市域掩膜统一裁切几何与贴图，避免界外出现条纹伪影。

网格与取点　渲染用 1024² 网格；鼠标取高程不走百万级三角面求交，而是在高程场上做射线步进求交（pickTerrain），不依赖矩阵刷新时机。

三维地标　全部程序化生成，1 个 three.js 单位 = 1 米。中式屋顶用自研曲面（反宇 + 檐口起翘 + 四角起翘），吊脚楼、斗拱、拱桥、悬索均为构件级建模；放真实 glb 进 assets/models/ 即可替换。

距离与车时　区县间用球面距离（haversine），乘以 1.32 的公路折算系数，按 52 km/h 平均车速估算；单日上限设为 3 个区县 / 5.5 小时。

行程排序　先以最近邻构造初始解，再用开放路径 2-opt 优化（固定起点不翻转首段）。

叁口径与局限 请评委注意

  • 海拔指县城所在地的平均海拔，不是区县最高点；“海拔幅度”才是境内最高与最低之差。
  • 里程与车时是估算值，按直线折算与平均车速计算，不反映实时路况、山路限速与轮渡，不能替代导航。
  • 地形不作测绘依据：30m 数据经重采样与视觉增强，用于呈现“山—水—城”格局，不作为工程或规划依据。
  • 三维地标为程序化示意模型，按公开尺寸还原体量与形制，细节（窗格、纹样、植被）为示意，不代表实测。
  • 区县数量为 38（26 区 + 12 县），其中万州单独使用标杆页 wanzhou/。

肆版权与素材

站内照片为真实拍摄素材，仅用于本作品展示；地形与影像数据来自上述公开来源，按其原始许可使用。三维模型、图表、动效均为本项目自行编写（原生 WebGL / SVG / Canvas），未使用付费模型库。

如用于公开发布或参赛展示，请保留本页的出处说明。

伍技术栈

原生 HTML / CSS / JavaScript，无框架、无构建；三维使用 Three.js（本地引入），后期（泛光 / SSAO）为自建管线；图表为手写 SVG；地形与数据在浏览器端解码，无后端、无数据库、无在线接口。
