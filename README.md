# 山城重庆 · 37 区县数字志

> 一个纯静态的重庆旅游数字志：真实地形、程序化三维地标、一条江的叙事主线，以及可用的行程规划与站内向导。

![首页](assets/pic/yuzhong/hero.jpg)

## 站里有什么

- **892 个页面**：37 个区县主页 + 415 个景点/美食/人文子页 + 12 个人文专页，全站 9000+ 链接、6000+ 图片，零断链、零裂图
- **立体地形**：真实 SRTM 高程（2048² 高程场 + 1024² 网格），地形/影像/水系/夜景四种模式，区县悬停高亮、点击飞入
- **三维地标**：9 座按真实米制程序化建模，关节点标注 + 尺寸/年代/结构数据可核对
- **一条江**：10 站叙事导航，滚动驱动进度，区县专属转场（12 纹样 × 6 动效 × 37 区县），旅程进度本地存档
- **行程规划**：选 2–5 个区县，自动排序分天、估算里程与车程，可导出 1080×1440 行程单
- **数据对比**：38 个区县的海拔 / 起伏 / 词条可交互排行，点击直达区县
- **站内向导**：本地意图识别 + 工具调用（排路线 / 查区县 / 切三维 / 开数据页），不联网、可解释

## 本地运行

纯静态，无构建步骤：

```bash
python -m http.server 8688 --bind 127.0.0.1
# 打开 http://127.0.0.1:8688/index.html
```

### 立体地形图（`terrain.js`）

真实 SRTM 高程场（`dem-data.js` 解码 2048² PNG）＋ 区县轮廓/悬停/点击 ＋ 四种模式（地形/影像/水系/夜景）。

**本次优化要点**：

- **掩膜统一**：几何与贴图同用 `HG.mask`（`maskGrid()`），消除界外横向条纹伪影
- **沙盘裙边**：掩膜外扩 2 圈（`buildSkirt()`）＋ 材质 `alphaTest`，界外灰板消失，只剩地形块侧壁
- **修索引 bug**：贴图分辨率 ≠ DEM 分辨率时按数据分辨率重采样（`kE/sx/sy_`），南半部不再被当成界外（此前表现为南半部发黑）
- **高程配色**：更亮的高程分层色带（绿→黄绿→土黄→棕→灰白），图例色带同步更新
- **山影**：西北光 315°/45° 的 hillshade，地形/水系/影像三种模式都叠加，影像模式也带立体感
- **等高线**：250m 一条，宽度随坡度自适应（视觉等宽），暗底＋暖色描边，可在「视角」行开关
- **标签分级**：远→主城，中→＋新区，近→全区县，配合原有避让逻辑
- **水系**：主河道（亮、微微浮出）＋ 湿岸外带（暗、更宽），并按市域掩膜分段裁剪（不再飘出界外）
- **夜景灯点**：按聚落成团（每区县若干城镇中心＋高斯外沿，越靠中心越亮）
- **制图要素**：指北针（随视角旋转）、比例尺（随缩放在 10/20/50/100/200 km 间换档）
- **高程剖面**：点「剖面」后在地形上点两点 → 地形上画剖面线 ＋ 右下角出高程曲线图（全长/最低/最高）；取点用**射线步进求交高程场**（`pickTerrain`），不依赖 `matrixWorld` 刷新时机、也不对百万级三角面求交，快且稳定
- **选中飞入**：点击区县镜头自动飞近（`tR=82, tP=1.0`）
