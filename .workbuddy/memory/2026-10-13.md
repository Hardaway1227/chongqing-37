## 八期：真实 DEM 地形（解决地形太粗糙）
- 需求：地形图模型太粗糙，去网上找清晰数据
- 数据源（免登录直链实测）：AWS Open Data Terrain Tiles（terrarium PNG，SRTM/ALOS 30m 派生，CC-BY）+ Esri World Imagery 卫星影像瓦片；MapTiler 需 key（403）
- 生成链路：z=10 全市 225 瓦片并行下载 → numpy 拼合 3495x3641 → 3x3 中值去坏点（427 个 SRTM 水体缺失/尖峰）→ data.js OUTLINE 栅格化掩膜（市域占 bbox 35.9%，掩膜置零大幅助压缩）→ 重采样 1024² + 高斯 0.7 平滑 + 2m 量化 → RGB PNG（R=高8位 G=低8位 B=掩膜）base64 内联
- 产物：assets/js/dem-data.js（576K，1024² 高程，校验渝中 300/合川 234/酉阳 854m ✓ 最高 2724m）、assets/js/dem-sat.js（720K，1536² 卫星影像 JPEG，与 DEM 同 bbox 对齐）
- terrain.js 改造：GW 176→512（52 万三角面，Uint32 索引 + uv）；HG 统一高度网格（真实 DEM 优先，程序化 elevProc 回退）；applyColors 顶点色 → 运行时贴图系统（1024² canvas：hillshade atan(zf*grad) az315/alt45 + 分层设色 LUT，按模式缓存 CanvasTexture）；新增「影像」模式（卫星图直接贴地形）；init async（decodeDEM/loadSat 失败回退）；垂直夸张 22→11 + H 场 3x3 平滑（修竖条纹伪影：陡峡谷 x 20x 夸张导致近垂直三角面）；边缘 4 层腐蚀羽化（沙盘底座平滑过渡）
- 踩坑：canvas 无法读 16bit PNG（须双通道 8bit 编码）；file:// 下 getImageData/WebGL 纹理会 taint，故全部数据 base64 data URI 内联；HG.e/HG.elev 属性名不一致导致 init 报 reading 19190
- 生成脚本：Python venv（numpy+pillow）在 .workbuddy/tmp/（已清理），方法记录在本日志
- 测试：terrain-test.js 四模式截图 + focus 选中全通过零错误；smoke.js 回归零错误
